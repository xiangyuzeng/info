## 三条改变判断的发现

1. **低分漏出已归零。** 最近 24h 境外放行 1,247 条中，reCAPTCHA 分数 ≤0.3 的是 **0 条**。172/策略3/策略4 已把低分人群吃尽，**再加任何分数阈值策略的新增召回为 0**。
2. **段枝宏预判的两条突破口同时发生了。** 漏出中 **41.9%** 不带 token 或 token 为空（他 09-11 明确预警的那条），**58.1%** 带 token 且分数 0.5–0.9（高分养号）。现有三条策略对这两部分都结构性无效。
3. **回测覆盖率最高的候选都不能用。** `网关uid 黑名单` 覆盖 84.4%，但热点 uid 次日留存仅 **0–5%**，是从同一份数据拟合出来的假象；`cid=105` 单条覆盖 98.7%，但 OTP 已填充的真实用户里有 **70 条**也是 cid=105。
