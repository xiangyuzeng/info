## 四、表二各字段的计算口径（写入审批表脚注）

| 字段 | 计算方式 |
|---|---|
| 整体调用量 | 观察窗口内 `scene_id='LKUS_push'` 的请求数 |
| 整体用户量 | 窗口内**去重手机号数**。本场景为登录前场景，`user_no` 约 97% 为空，无法用用户号 |
| 命中样本量 | 该策略在窗口内的命中数，写成 `N（pv）、M（uv）` |
| 风险样本量 | 命中样本中按 SOP §3.8 判为**正常用户**的条数 🔴 定义待田志鲔确认 |
| 暂无法判断样本量 | 命中样本中按 SOP §3.7 证据不足（单一特征）判为**暂无法判断**的条数 |
| 准确率 | `(命中样本量 − 风险样本量 − 暂无法判断样本量) ÷ 命中样本量` 🔴 口径待确认 |
| 误伤比例 | `风险样本量 ÷ 命中样本量` |
| 近7日同期平均调用量/用户量 | 前 7 天同一时段形状的均值 |
| 是否覆盖核心活跃时段 | 用逐小时分布举证，不得直接断言 |
| 是否达到命中样本参考门槛 | 普通策略 ≥10，高风险强拦截策略 ≥20（SOP §二） |

**重跑命令**：

## 五、回滚触发与止损（SOP §1.8）

**触发条件（满足任一即执行）**：
- 命中样本中出现 **OTP 已填充**（`filled=1`）的手机号 —— 这是确定误伤，不需要再讨论；
- 命中中出现 +1/+86 区号；
- 客服/业务侧收到境外用户收不到验证码的反馈；
- 宙斯报错大盘出现与本策略相关的新增异常。

**止损动作**（按 SOP §1.8，**电话报备**，不得仅发飞书等回复）：
1. 立即判断影响范围；
2. 关闭策略 / 切回观察模式 / 缩小生效范围，三选一或并行；
3. 留痕：发现时间、确认时间、报备时间、止损时间、影响范围、处置动作、恢复情况。

**R3C1 的已知误伤形态**：老版本客户端（1.4.16 / 1.3.65 / 1.3.32）的真实境外用户本就不发 token。若观察期误伤集中于此，止损方式不是下线整条策略，而是**加 `version 版本号大于等于 1.4.30` 护栏**（代价：覆盖从 41.5% 降至 7.1%）。

## 六、本轮特征类策略关不上的缺口，需要非 RMS 手段

即使 R3C1 + R3C2 全部上线，预计境外日发送仍约 **559 条**，是 150 条目标的 3.7 倍。建议同步推进（均非 RMS 侧，需对应团队）：

1. **upush / Twilio 地区权限或日上限**：对攻击前基线为 0 的目的国设置发送白名单或日上限。这是唯一能直接把成本按住的手段，且不经过风控误伤路径。
2. **监控告警**（`01_` 第六节）：境外小时请求 >300；境外占比 >90%；upush 境外日发送 >150；任一在线策略小时命中连续 2 小时为 0；境外请求中不带 token 的小时占比突增。
3. **IP C 段名单每日刷新**作为运营动作（非静态策略），配套名单回收机制。
4. **研发特征排期**：uid 实时场景覆盖、userAgent 机型、ASN/机房标签（`03_` 第四节）。
