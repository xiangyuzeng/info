## 六、综合分析

目前数据呈现出两个不同的结论：

### 支持上线的因素

1. 非北美区号 + Token ≤0.3 有非常明显的风险区分能力。
2. 非美国 IP + 一 IP 多手机号的风险特征非常明显。
3. 策略命中后，IP Country 与手机号国家高度不一致。
4. +1 用户 IP 与手机号国家不一致仅 1.1%，正常北美用户误伤风险相对较低。
5. 当前策略包含多个风险条件叠加，而不是单独依赖 Token 分数。

### 暂不支持直接上线的因素

最主要的问题是：

> 非美国 IP 的 Token ≤0.3 只有 21.0%，而美国 IP 却达到 60.6%。

也就是说，`realIpCountry != 美国` 与 `Token ≤0.3` 在当前数据中没有形成预期的正向相关关系。

因此，目前数据更强地支持：

```
非北美区号 + Token ≤0.3
```

以及：

```
非美国 IP + 一 IP 多手机号
```

但还不足以充分证明：

```
非北美区号 + 非美国 IP + Token ≤0.3
```

- 所以「IP=美国」组的低 Token 请求上限是 35 + 329 = **364 条**，不可能是原文写的 **743 条**。
