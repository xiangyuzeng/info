## 一、数据口径

本次分析基于 2026 年 5 月至 9 月（过去 120 天）的短信数据，共 **17,782 条**短信请求。

数据维度定义如下：

- **Rows: IP Country** —— 发起 SMS 请求的源 IP 所属国家
- **Columns: Mobile Country Code** —— 短信目标手机号所属国家/地区代码
- **Cell Value: SMS 短信 Count** —— 对应 IP Country → Mobile Country Code 的短信数量

因此，本数据本质上是一个 **SMS Country-Pair Matrix**（IP 来源国家 → 手机号国家），可以用于分析短信来源地域、跨境发送模式以及潜在的 SMS Abuse / OTP Abuse。

## 四、Pakistan 是当前最值得关注的异常来源

Pakistan IP 来源共产生 **3,631 条 SMS**，占总量 **20.4%**，但真正值得关注的不是绝对数量，而是其增长趋势：

| 月份 | Pakistan SMS |
|---|---|
| May | 25 |
| Jun | 387 |
| Jul | 598 |
| Aug | **1,482** |
| Sep* | 1,139 |

从 May 到 August，从 25 条增长到 1,482 条，约增长 **59 倍**。同时：

- July → August：**+148%**
- August 达到 Pakistan 来源的峰值
- September 当前统计周期已经达到 1,139 条

这种从低基数快速爬升、随后持续维持高位的模式，明显区别于普通稳定业务流量，更符合需要进一步调查的 **abnormal SMS activity / potential SMS abuse** 特征。

因此：

> Pakistan IP 来源目前应作为 **P1 优先级**进行调查。

---

## 五、为什么 Pakistan 比 Malaysia / Singapore 更值得关注？

不能简单地因为某个国家 SMS 数量高，就认定其为黑产。需要同时观察：

> IP Country → Mobile Country Code

也就是「短信请求从哪里来」与「短信发往哪里」。

### Malaysia

Malaysia 共 2,301 条，其中约 **99.1%** 为 Malaysia IP → Malaysia Mobile。这说明其 IP 来源国家和手机目的地高度一致，具有明显的本地业务特征。

### Singapore

Singapore 共 2,085 条，其中约 **93.6%** 为 Singapore IP → Singapore Mobile。同样具有较强的地理一致性。

因此，目前更合理的判断是：

> Malaysia / Singapore 虽然 SMS volume 较高，但 IP Geo 与 Mobile Country Code 高度一致，暂时没有足够证据仅凭该数据认定为黑产。

相比之下，Pakistan 的快速增长以及其具体 Country Pair 分布更加值得关注。

---

## 六、真正需要重点分析的是跨境 Country Pair

黑产判断不能停留在：

> 「Pakistan 发了很多 SMS。」

更重要的是分析：

> Pakistan IP → 哪些国家的 Mobile？

例如重点检查：

- Pakistan → US
- Pakistan → UK
- Pakistan → Singapore
- Pakistan → Malaysia
- Pakistan → 其他互不相关国家

如果发现一个 IP 来源国家同时大量发送到多个互不相关的国家/地区，且存在明显的短时间集中发送，则其风险显著提高。

尤其是出现以下组合时，需要重点关注：

```
单一国家/ASN → 多个国家 → 大量手机号
```

或者：

```
少量 IP → 大量账号 → 大量手机号 → 大量 SMS
```

这类模式可能与 SMS Pumping、OTP Abuse、Fake Account Registration、Account Takeover、SMS Fraud、Automated Bot Activity 等行为相关。

---

## 七、目前可以支持的黑产判断

基于现有数据，可以得出的是：

**1. 已存在明显的异常 SMS 流量信号**
整体 SMS 在 August 明显增长，并且 Pakistan 来源同步出现大幅增长。

**2. Pakistan 是目前最明显的异常来源**
其占比达到 20.4%，同时从 May 到 August 增长约 59 倍，具有明显的异常爆发特征。

**3. 目前不能仅凭 IP Country 直接确认黑产**
国家维度的数据只能说明 `Potentially Suspicious / Anomalous Traffic`，而不能直接证明 `Confirmed Fraud / Confirmed Criminal Traffic`。最终是否属于黑产，需要结合更细粒度的行为数据。

**4. Malaysia / Singapore 目前风险相对低于 Pakistan**
虽然流量较高，但绝大多数为 Malaysia → Malaysia、Singapore → Singapore，地理关系相对合理，因此暂不应仅凭 volume 将其定性为攻击。

---

## 八、建议进一步验证的黑产特征

为了将结论从「异常流量」升级为「高可信度黑产攻击」，建议进一步下钻以下维度：

### IP / Network

Unique IP 数量 · SMS requests per IP · Requests per minute/hour · ASN/ISP · Cloud/VPS provider · Proxy / VPN / Tor · IP Reputation · Datacenter IP · IP rotation pattern

### Account

Unique Account · SMS requests per account · 新注册账号占比 · 同一账号关联手机号数量 · 同一账号短时间 SMS burst · 注册 → SMS → OTP 的时间关系

### Mobile

Unique Phone Number · SMS per phone · 国家/地区分布 · 同一手机号被不同账号使用的情况 · 大量随机手机号模式

### OTP

SMS Success Rate · OTP Delivery Rate · OTP Verification Success Rate · OTP failure / retry rate · SMS → OTP verification conversion rate

### Behavioral

IP → Account → Phone 的关联关系 · Device fingerprint · Login / Registration correlation · Velocity · Burst behavior · Repeated requests · 多账号共享相同 IP / Device
