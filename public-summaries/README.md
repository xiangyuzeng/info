# 公开摘要 / Public Summaries

本目录存放可对外分享的**脱敏公开摘要**。每份摘要对应一份内部受控文档，
保留结构、结论、评估证据与流程原则，移除任何可被用于规避防护的操作细节。

文件名使用纯 ASCII，便于在聊天 / 邮件里直接发链接。

## 统一的脱敏口径

两份摘要一致地**移除**以下内容：

- 规则原文与布尔表达式
- 阈值数值（含调整前后的新旧值）、统计时间窗口、比较运算符
- 依赖的特征字段名、客户端标识取值
- 区号名单、内部策略 ID、内部系统与厂商名称
- 监控告警阈值、已知绕过路径、当前未覆盖的检测维度
- 分策略的上线时间点与时间窗
- 人员姓名、手机号、IP 地址

一致地**保留**：策略结构与分组、评估与回测证据、拦截率与误拦率等结果指标、
上线流程、回滚原则、以及流程层面的经验与改进建议。

> 这些防护多数仍在运行。摘要之所以按上述口径脱敏，是因为公开具体规则与门槛
> 等同于把规避方法一并公开。如需完整内容，请通过内部渠道获取原始文档。
