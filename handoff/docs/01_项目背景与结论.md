# 01 · 项目背景与关键结论

## 一句话

2026-09-03 起，LKUS（瑞幸咖啡北美）App 的短信验证码接口遭黑产刷量（SMS pumping / AIT）：
攻击方向**我们没有客户的国家**批量请求验证码，每条短信由公司真实付费，攻击方从终端运营商侧分成。
截至数据窗口末（2026-09-10 06:32 UTC）**仍未压制**。

## 五条关键结论（看板与技术报告共用）

1. **仍未压制。** 非 +1/+86 实发短信从攻击前日均 66 条涨到 2,337 条/天（35.6 倍），曲线无拐点。
2. **正常美国用户零影响。** +1 日发送量稳定 900~1,400，验证码填充率稳定 94~98%。
3. **攻击是按我们的阈值校准过的。** 48.4% 的（区号,小时）格子 ≤30，承载 30.1% 的攻击请求，
   现网规则根本碰不到；阈值降到 15 可压到 5.3%。
4. **美国机房 IP 是同一伙人。** 六项特征交叉印证（目的区号名单相同、一 IP 多手机号 66.8%、
   iPhone 占比 0.9%、98.9% 的网关标识只调短信接口、32.6% 的号码被 ≥2 个国家的 IP 请求过、IP 集中在德州机房段）。
   而 9/9 上线的两条策略都按「来源国家不是美国」过滤，**设计性放过了这批流量**。
5. **最有效的两条策略一直没生效。** 9/4 就已配置完成，停在「已配置但未生效」状态 6 天；
   启用后拦截率 53.8% → 95.2%，且攻击前 25 天回测对美国真实用户零命中。

## 已在技术报告中更正过的两件事（不要写回旧说法）

  已改为三条监控告警阈值。
