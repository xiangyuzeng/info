## 一、评估依据说明（正文）

本次命中样本共 2,459 条。

其中 **2,339 条**，同时满足「IP/设备聚集」与「API 链路异常」两类特征：这些请求所在 IP 在 60 分钟内关联了
3 个以上手机号（中位数为每 IP 4 个号），
且其网关 uid 在全场景范围内**只出现在短信场景**，从不登录、不下单、不支付；
其中 984 条的手机号还落在同一 IP 的连号簇内（号码数值间隔 ≤1000，典型如同一号段批量生成）。

命中样本中共有 **785 条**命中「OTP 行为」这一硬标签 —— 短信已实际下发，但验证码**从未被填写**
（同期 +1 正常用户的验证码填充率为 95%~96%，本组为 0%）；其中 **10 条**不属于上一组，
即**仅凭 OTP 行为一项即可独立佐证**，不依赖 IP 聚集。

再有 **33 条**，虽不满足上述两组的组合，但仍满足 ≥2 类独立特征交叉（手机号风险 + IP 聚集 / API 链路），
按 SOP 判为确认黑产。

剩余 **77 条（3.1%）** 只满足单一类特征，按 SOP"证据不足标暂无法判断"处理，
**未计入黑产**，也未用于抬高策略准确率。

全部命中样本中，手机号区号与 IP 所在国家不一致的比例为 **97.1%**；
152 个手机号在 24 小时内被 ≥2 个不同 IP 国家请求过。
